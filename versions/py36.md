# Python 3.6 概要と変更点まとめ

Python 3.6（2016年12月リリース / EOL）では、開発体験を飛躍的に向上させた f-strings、変数型注釈、非同期内包表記が導入され、内部的にも辞書順序保持（CPython実装詳細）などの高速化が行われました。
