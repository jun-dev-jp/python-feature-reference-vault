# Python 3.15 概要と変更点まとめ

Python 3.15（2026年10月リリース / 最新安定版）は、起動時間を抜本的に短縮する「明示的遅延インポート（`lazy import`）」、長年待望された不変辞書「`frozendict`」および「`sentinel`」組み込み型、内包表記でのアンパック、型システムの `TypeForm` / `TypedDict` 拡張、そしてフリースレッド向け安定ABI（`abi3t`）や新プロファイラ（Tachyon）など、実用性と堅牢性を大幅に引き上げたメジャーリリースです。
