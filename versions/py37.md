# Python 3.7 概要と変更点まとめ

Python 3.7（2018年6月リリース / EOL）では、ボイラープレートを大幅に削減する `dataclasses` や非同期コンテキストを支える `contextvars`、型評価の将来に向けた `from __future__ import annotations` が導入され、辞書の挿入順序保持が言語仕様として正式保証されました。
