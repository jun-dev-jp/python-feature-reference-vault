# Python 3.5 概要と変更点まとめ

Python 3.5（2015年9月リリース / EOL）は、モダンPythonの基礎となる「ネイティブ非同期構文」と「型ヒントシステム」が初めて導入された歴史的マイルストーンとなるバージョンです。

---

## 主な変更点と採択PEP

| 分類 | トピック | PEP | リンク |
|:---:|:---|:---:|:---|
| 言語仕様 | ネイティブコルーチン (`async` / `await`) | PEP 492 | [[language/py35/101-async-await\|101-async-await]] |
| 型システム | 型ヒント（Type Hints）基本システムの導入 | PEP 484 | [[typing/py35/102-type-hints-basics\|102-type-hints-basics]] |
| 言語仕様 | 辞書・リストのアンパック一般化 (`*` / `**`) | PEP 448 | [[language/py35/103-unpacking-generalizations\|103-unpacking-generalizations]] |
| 標準ライブラリ | サブプロセスの高水準API `subprocess.run()` | - | [[library/py35/104-subprocess-run\|104-subprocess-run]] |
| 言語仕様 | 行列積演算子 `@` の追加 | PEP 465 | - |
| 実行基盤 | `.pyo` ファイル廃止と `.pyc` への統一 | PEP 488 | - |
