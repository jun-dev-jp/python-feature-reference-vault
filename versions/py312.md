# Python 3.12 概要と変更点まとめ

Python 3.12（2023年10月リリース / バグ修正サポート）では、型パラメータ構文（PEP 695）による `type` 文やジェネリクス定義の刷新、f-strings の引用符ネスト制限撤廃（PEP 701）、サブインタプリタごとのGIL分離（PEP 684）など、長年の制約を打ち破る近代化が断行されました。

---

## 主な変更点と採択PEP

| 分類 | トピック | PEP | リンク |
|:---:|:---|:---:|:---|
| 言語仕様 | 型パラメータ構文 (`type` 文, クラス/関数ジェネリクス) | PEP 695 | [[language/py312/801-type-parameter-syntax\|801-type-parameter-syntax]] |
| 言語仕様 | f-strings 構文制限の撤廃（ネスト・バックスラッシュ解禁） | PEP 701 | [[language/py312/802-syntactic-formalization-fstrings\|802-syntactic-formalization-fstrings]] |
| 型システム | `@override` デコレータによる基底クラス実装検証 | PEP 698 | [[typing/py312/803-override-decorator\|803-override-decorator]] |
| 実行基盤 | サブインタプリタごとのGIL分離（Per-Interpreter GIL） | PEP 684 | [[language/py312/804-per-interpreter-gil\|804-per-interpreter-gil]] |
| 型システム | `**kwargs` の型付けのための `Unpack[TypedDict]` | PEP 692 | - |
| 実行基盤 | 低オーバーヘッド監視API（プロファイラ・デバッガ向け） | PEP 669 | - |
