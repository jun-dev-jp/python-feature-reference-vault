# Python 3.8 概要と変更点まとめ

Python 3.8（2019年10月リリース / EOL）では、代入式（セイウチ演算子 `:=`）と位置専用引数構文 (`/`) が加わり、型システムにおいては静的ダックタイピング（`Protocol`）や固定値型（`Literal`）などが標準ライブラリに統合されました。
