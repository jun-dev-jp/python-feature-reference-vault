# Python 3.13 概要と変更点まとめ

Python 3.13（2024年10月リリース / 最新安定版）は、Pythonの将来を左右する二大実行基盤改革である「フリースレッドCPython（GIL無効化モード）」と「実験的JITコンパイラ」が初めて同梱された記念碑的リリースです。さらに型システムでは安全な絞り込み `TypeIs`、カラー対応の新REPLなどが導入されました。
