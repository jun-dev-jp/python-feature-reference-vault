# Python 3.14 概要と変更点まとめ

Python 3.14（開発中 / 2025年秋〜2026年リリースサイクル）は、長年の型注釈評価論争に決着をつける「アノテーション遅延評価（PEP 649 / 749）」や、安全なDSLやHTML/SQL生成を実現する「テンプレート文字列（PEP 750: t-strings）」が注目される次期メジャーリリースです。
