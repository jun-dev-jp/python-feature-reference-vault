# Python 3.9 概要と変更点まとめ

Python 3.9（2020年10月リリース / セキュリティサポート期間）では、組み込みコレクションでの型引数直接指定（`list[int]` 等）、辞書マージ演算子 (`|`)、標準IANAタイムゾーン `zoneinfo` が導入され、型アノテーション記述のボイラープレートが大幅に削減されました。
