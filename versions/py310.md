# Python 3.10 概要と変更点まとめ

Python 3.10（2021年10月リリース / セキュリティサポート期間）の最大の目玉は「構造的パターンマッチング (`match`/`case`)」です。さらに型ユニオン演算子 (`X | Y`) や括弧付きコンテキストマネージャが導入され、エラーメッセージの親切化（トレースバック改善）も進みました。

---

|:---:|:---|:---:|:---|
| 言語仕様 | 構造的パターンマッチング (`match` / `case`) | PEP 634, 635, 636 | [[language/py310/601-pattern-matching\|601-pattern-matching]] |
| 型システム | 型ユニオン演算子 (`int \| str`) | PEP 604 | [[typing/py310/602-union-operator\|602-union-operator]] |
| 言語仕様 | 括弧付き複数コンテキストマネージャ | - | [[language/py310/603-parenthesized-context-managers\|603-parenthesized-context-managers]] |
| 型システム | ユーザー定義型絞り込み (`TypeGuard`) と `TypeAlias` | PEP 647, 613 | [[typing/py310/604-typeguard-and-typealias\|604-typeguard-and-typealias]] |
| 標準ライブラリ | `zip(..., strict=True)` による長さ検証 | PEP 618 | - |
| 言語仕様 | 正確な行番号と構文エラー（SyntaxError）メッセージ改善 | - | - |
