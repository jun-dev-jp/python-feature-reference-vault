# Python 3.11 概要と変更点まとめ

Python 3.11（2022年10月リリース / バグ修正サポート）は「Faster CPython」プロジェクトによる10〜60%の大幅な実行速度向上が話題となったバージョンです。言語機能としても例外グループ (`except*`)、TOMLパーサ (`tomllib`)、`Self` 型など多数の強力な改善が行われました。
